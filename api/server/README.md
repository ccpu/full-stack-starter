# @internal/server

This is the NestJS server for the full-stack starter project. It uses Fastify as the HTTP server and provides a REST API with Swagger documentation.

## Running Locally

Install dependencies and start the server in development mode:

```sh
pnpm install
pnpm start:dev
```

The server will be available at [http://localhost:49252/api](http://localhost:49252/api) and Swagger docs at [http://localhost:49252/docs](http://localhost:49252/docs).
